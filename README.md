# القرآن الكريم - Full Offline Ad-Free Android App (QCF4)

تطبيق القرآن الكريم كاملاً بالخط العثماني (رواية حفص عن عاصم - مصحف المدينة النبوية QCF4) بدون إعلانات نهائياً.

---

## 🌟 مميزات التطبيق

1. **بدون إعلانات 100%**: خالي تماماً من الإعلانات والتتبع.
2. **عرض المصحف الشريف (QCF4)**: خط مجمع الملك فهد لطباعة المصحف الشريف (604 صفحة كاملة) مع الخطوط الخاصة بكل صفحة.
3. **فهرس السور والأجزاء**: فهرس كامل لـ 114 سورة و 30 جزءاً مع الانتقال السريع.
4. **محرك بحث في الآيات**: بحث فوري في نص جميع آيات القرآن الكريم مع إزالة التشكيل التلقائية.
5. **مشغل صوتي مع مشاهير القراء**: استماع للآيات (العفاسي، المنشاوي، الحصري، عبد الباسط، الشريم، الغامدي).
6. **التفسير والترجمة**: دعم عرض التفسير الميسر، تفسير ابن كثير، السعدي، والترجمة الإنجليزية.
7. **علامات القراءة (الفواصل)**: حفظ الفواصل وموضع آخر صفحة تمت قراءتها تلقائياً.
8. **أنماط قراءة متعددة**: (مصحف ورقي، وضع ليلي هادئ، وضع الزمرد، وضع السواد التام AMOLED).

## 📱 كيف تقوم بتوليد ملف الـ APK بأسهل طريقة (3 خيارات):

### **الخيار الأول (الأسهل والأسرع): التوليد الآلي عبر GitHub (بدون تثبيت أي برامج)**
1. ارفع مجلد المشروع هذا إلى حسابك في **GitHub**.
2. سيقوم ملف الـ Workflow المعرف في `.github/workflows/build-apk.yml` بالعمل تلقائياً.
3. خلال **دقيقتين فقط**، ستجد ملف الـ `Quran_App_AdFree.apk` جاهزاً للتحميل المباشر من تبويب **Actions** أو **Releases** في مستودعك على GitHub!

---

### **الخيار الثاني: التوليد المباشر عبر PWABuilder (نقرة واحدة)**
1. قم برفع التطبيق على أي استضافة مجانية (مثل Vercel أو GitHub Pages) أو خادم محلي.
2. افتح موقع [pwabuilder.com](https://www.pwabuilder.com/).
3. أدخل رابط موقعك واضغط **Generate Android APK** لتحميل ملف الـ APK مباشرة.

---

### **الخيار الثالث: البناء المحلي باستخدام Android Studio**
إذا كان لديك **Android Studio** مثبتاً على جهازك:
```bash
# 1. تثبيت الحزم
npm install

# 2. بناء ملفات الويب
npm run build

# 3. مزامنة تطبيق أندرويد
npx cap sync android

# 4. فتح المشروع في Android Studio
npx cap open android
```
ثم اضغط **Build > Build APK** في Android Studio.
